# FIH Past Projects

Past projects of the [Frugal Innovation Hub](https://www.scu.edu/engineering/labs--research/labs/frugal-innovation-hub/)
at Santa Clara University. Students built them with partner organizations, in FIH projects, classes, and senior design.

**Reviving a project:** contact FIH. The repository is moved back to the active FIH organization, where
the current contribution rules and CI checks apply. Please do not start new work here.
